# 大狗答题 — C++/算法 CSP 练习系统

CSP-S 初赛真题练习与模拟考试工具，基于 Web Audio 和 Canvas 的角色反馈系统。

## 题库
- **CSP-S 2025** 初赛真题（43题）
- **CSP-S 2021** 初赛真题（43题）
- 后续可自行扩充题目

## 功能
- **练习模式**：按知识点分类练习，答对大狗叫+特效，答错哈基米哈气+解析
- **模拟考试**：自动抽 15 选择 + 3 阅读 + 2 填空，2 小时倒计时

## 运行
直接用浏览器打开 `index.html` 即可（需本地服务器，推荐 VS Code Live Server 或 `python3 -m http.server 8080`）。
