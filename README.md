## 🎮 功能

- **练习模式**：按知识点分类练习，答对🐶大狗叫+特效，答错🐱哈基米哈气+解析
- **模拟考试**：自动抽 15 选择 + 3 阅读大题 + 2 填空大题，2 小时倒计时，静默答题，交卷出分
